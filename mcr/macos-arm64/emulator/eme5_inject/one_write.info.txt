# eme5_inject/one_write — the FOUNDING-FREE inject fixture
#
# Victim: write(1,"one\n",4); return 0;  (programs/mcr_one_write.c — a direct
# write syscall, which the main-image interpose table captures, unlike puts()).
#
# Recorded via: ct_cli/tests/record_macos_eme5_inject.nim
#   = the injected record path (runInject imRecord, the SIP-off PC-hijack of a
#     suspended child at pre-dyld T0 = __dyld_start) with CT_STAGE0_INCHILD_SETUP
#     explicitly CLEARED — the plain recipe, i.e. the recorder's DEFAULT
#     configuration.
#
# ============================================================================
# WHY THIS FIXTURE IS FOUNDING-FREE ON PURPOSE
# ============================================================================
#
# It carries predyldRecordCount == 0: no pre-dyld founding svc stream.  That is
# its JOB.  It is the only fixture that drives the emulator's no-founding-stream
# FALLBACK path — `if not havePredyldStream:` in
# codetracer-native-recorder/ct_emulator/src/ct_emulator/ctfs_bridge.nim — where
# the OS-sim host-shortcuts dyld's whole bring-up surface instead of serving it
# from the recording.
#
# THE FALLBACK IS NOT DEAD CODE — MEASURED, NOT ASSUMED (2026-07-29):
#   * The recorder's founding capture is OPT-IN.
#     predyld_svc_capture.inChildSetupRequested() is
#     `getEnv("CT_STAGE0_INCHILD_SETUP") == "1"`, documented "default ->
#     byte-identical normal path".  Every DEFAULT-configuration macOS recording
#     therefore has no founding stream and lands on this path.
#   * THIS recording is such a recording, made with the current recorder: 0
#     founding evOsPredyldSyscall records, and its replay takes the fallback for
#     every svc it issues.
#   * eme5/null_main and eme5/one_puts are also founding-free but cover the
#     fallback NOT AT ALL: they fault at PC=0 after 20 instructions, before any
#     svc is issued.  Nothing else covers it.
#   * Deleting the fallback would make every default-configuration macOS
#     recording stop at its FIRST svc instead of running dyld's bring-up.
#
# The founding-ARMED counterpart is eme5_inject_founding/.
#
# OPEN, FOR THE OWNER.  The fallback's OS-sim answers are FABRICATED
# (task_self_trap -> 0x103, csrctl -> 0x6f), which the replay contract deprecates
# in favour of serving recorded results.  The right way to retire it is to make
# founding capture the recorder DEFAULT; at that point it becomes genuinely
# unreachable and it — and this fixture — can be removed together.  Deleting it
# before then removes a capability, not a fake.

# ============================================================================
# RE-RECORDED 2026-07-29 — THE PREVIOUS RECORDING NO LONGER REPLAYED
# ============================================================================
#
# The fixture that stood here was recorded before `captureCommpage` existed, so
# it carried no `t_start.comm` member.  Once the emulator stopped substituting
# the REPLAY HOST's commpage for a missing capture — correctly: its boot-stable
# machine-identity words (CPU_CAPABILITIES, NCPUS, CACHE_LINESIZE, CPUFAMILY,
# MEMORY_SIZE) describe the replay machine, not the recorded one, and no
# read-twice check can detect that — the old recording died at instruction 30 on
# an honest memory fault and covered nothing at all.
#
# The re-record uses the SAME recipe and preserves the fixture's meaning
# exactly.  What moved:
#
#                            previous            this recording
#   instructionsExecuted      198,408              192,927
#   stop PC                 0x1000125B4          0x100014E04
#   terminus                  fsgetpath            csrctl
#   svcTrace entries              9                    6
#   mach traps               3 / 3 handled        2 / 2 handled
#   BSD syscalls             6 / 5 handled        4 / 3 handled
#   osSimStubCount                1                    1
#   predyldRecordCount            0                    0
#   totalEvents                 168                  168
#   write event geid           1143                 1143
#   commpage pages mapped         2 (LIVE HOST)        2 (from t_start.comm)
#
# The TERMINUS moved for a second, independent reason, on the same day: the
# OS-sim used to answer csrctl (BSD #483) from a compile-time constant
# (HostCsrActiveConfig = 0x6F) measured on one developer's Mac.  The active SIP
# configuration is a fact about the RECORDED machine and the emulated guest
# branches on it, so the handler now reads it from the recording and declines
# loudly when the recording does not carry it.  No recorder captures it yet, so
# the replay stops there — correctly.  That decline, not fsgetpath, is this
# fixture's terminus until the recorder gains the capture.
#
# It also modernizes the container: the recording now carries `t_start.mem` /
# `t_start.regs` / `t_start.sysregs` / `t_start.stack` / `t_start.comm` /
# `exe.macho` rather than the retired `cp0.mem` / `cp0.regs` names.
# test_macos_inject_seed was still asking for the `cp0.*` names and passed only
# because the old fixture was old enough to still carry them — two of its checks
# were asserting the fixture's AGE, not its coherence.  Fixed with the re-record.
