eme5_predyld_prestamp/one_write.ct — DERIVED, NOT RECORDED
===========================================================

What it is
----------
The pre-stamping control for macOS founding-thread attribution.  A recorder
from before founding SP stamping wrote no `recordcfg` member and stamped every
`evOsPredyldSyscall` header's ctTid 0; such a trace must still load, with
attribution inactive (the identity projection).  No recording of that shape is
kept any more, so this file is derived from ../eme5_predyld/one_write.ct by
undoing exactly what stamping added:

  * the `recordcfg` member is dropped;
  * every `evOsPredyldSyscall` header's ctTid is set to 0 (1952 stamps).

Every other member is copied byte for byte, in directory order.  The rewritten
thread stream `t00000000000` is stored as one zstd frame with no seek index, so
its index member `i00000000000` is dropped with it (the loader reads both
forms).  No event other than the founders, and no payload byte, changes.

How it is made
--------------
  bash mcr/macos-arm64/emulator/eme5_predyld_prestamp/derive.sh

which runs codetracer-native-recorder's
ct_emulator/tests/gen_prestamp_control_fixture.nim over
tests/support/prestamp_derivation.nim.  The derivation is a pure function of
the source: two runs on m4 wrote identical bytes.  Re-derive it whenever
eme5_predyld is re-recorded, and commit both together.
