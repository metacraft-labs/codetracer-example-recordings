# THE DRIVER MUST BUILD ITS OWN LEAN INTERPOSE DYLIB.  With the FULL
# libct_interpose.dylib (what `just build-interpose` produces) the founding-armed
# child WEDGES: the C installer reports status 0x2C2C2CDE and patches its 169

# parent's EXC loop spins ~13.8M times and the run dies as iwoTimeout with
# `handedOff=false maxBandCount=0 founding=0`.  Reproduced 5/5.  With the LEAN
# (-d:ctLeanRecord) dylib the same driver records cleanly, 5/5.  The driver now
# builds the lean dylib itself instead of taking whatever happens to be on disk —
# before that fix the recipe silently depended on whether a sibling driver had
# last overwritten libct_interpose.dylib.
